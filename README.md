# SQLModel

Exercice de découverte de [SQLModel](https://sqlmodel.tiangolo.com/) avec une base SQLite.

## Installation

```bash
python -m venv .venv
.venv\Scripts\activate   # Windows
pip install -r requirements.txt
```

## Lancement

```bash
python main.py
```

Le script crée `database.db`, insère quelques héros puis les affiche.
